# Shop Local App

A modern shopping discovery app that helps users find local shops, browse by room, and save their favorites.

## 🌐 Live Preview

**[View App](https://id-preview--3ec5f790-7747-4f53-99de-20fdd9178f82.lovable.app)**

## ✨ Features

- **Shop by Room** – Browse products organized by room categories
- **Local Shops** – Discover nearby local businesses
- **Pick of the Week** – Featured curated selections
- **Favorites** – Save and manage your favorite items
- **Certifications** – View shop certifications and credentials

## 🛠️ Tech Stack

- **React 18** – UI framework
- **TypeScript** – Type-safe development
- **Vite** – Fast build tooling
- **Tailwind CSS** – Utility-first styling
- **shadcn/ui** – Accessible component library
- **React Router** – Client-side routing

## 🚀 Getting Started

```bash
# Clone the repository
git clone <your-repo-url>

# Navigate to project directory
cd <project-name>

# Install dependencies
npm install

# Start development server
npm run dev
```
